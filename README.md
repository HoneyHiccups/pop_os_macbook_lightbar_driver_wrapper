This is a wrapper that sccans input from the touchbar of a macbook mine is a 2016 macbook pro 15in it then will work with pop os brightness to allow the touvhbar to control the brightness of the keyboard backlight

It was was one thing that I really liked about pop. So my brainless body had an idea. Driver wrapper watch the events from the touchbar and then just change the val on the pop os side.
